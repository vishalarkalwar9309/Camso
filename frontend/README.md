# CAMSO by CEAT - Flutter Launch 1 Frontend

This project is a Flutter recreation pass based on the uploaded Figma/React source project.

## Run

1. Open this folder in VS Code.
2. Run `flutter pub get`.
3. Run `flutter run`.

## Notes

- The desktop fake-phone frame from the React prototype is intentionally not included; Flutter runs directly on the device.
- Mock data is used, as in the current frontend prototype.
- Dealer Google Maps enhancement is intentionally left for the later change phase.
- Search recent-search clear-all and notification unread state are implemented in shared app state.
- Product image URLs currently mirror the mock data source and therefore require internet access for images.
